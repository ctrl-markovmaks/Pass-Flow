# Passenger Flow

Приложение создано студентом Российского университета транспорта для более удобного подсчёта пассажиропотока на маршрутах. Приложение может обновляться, но обновления не гарантированы.



Функции приложения:



Подсчёт пассажиров (вошедшх и вышедших отдельно)

Определение GPS (чтобы потом вспомнить, где был сделан замер)

Фиксация времени прибытия и отправления с остановочного пункта

Сценарий работы:



Даёте разрешение на геолокацию

Нажимаете кнопку "Прибытие"

Считаете количество вошедших и вышедших

Нажимаете кнопку "Отправление"

После завершения обследования пассажиропотока (обычно несколько остановок или весь маршрут в одну сторону), нажимаете снизу кнопку "Завершить измерение"

Приложение не заменяет форму 4.3 Приложения 4 Распоряжения Минтранса России от 28.12.2016 N НА-197-р. После возвращения в офис или домой следует заполнить форму или её аналог данными из приложения
